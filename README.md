**Quitar credenciales de GitHub de Windows**

1. Presionar Windows + S.
2. Buscar "Administrador de credenciales" y abrir (con escribir "credenciales" aparece.).
3. Seleccionar Credenciales de Windows.
4. Donde diga git:https://github.com o parecidos, seleccionar la flecha desplegable.
5. Presionar quitar.
